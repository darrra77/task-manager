# Task Manager

REST API для управления задачами на Spring Boot с веб-интерфейсом и авторизацией пользователей.

## Стек технологий

- Java 21
- Spring Boot 3.5.16
- Spring Web MVC
- Spring Data JPA
- Spring Security + JWT
- PostgreSQL
- Thymeleaf
- Maven
- Docker + Docker Compose
- JUnit 5 + Mockito

## Функциональность

- Регистрация и авторизация пользователей
- Аутентификация через JWT и Basic Auth
- Создание, просмотр, редактирование и удаление задач
- Изменение статуса и приоритета задач
- Поиск и фильтрация задач
- Разграничение прав доступа (USER / ADMIN)
- Веб-интерфейс для работы с задачами
- Хранение данных в PostgreSQL

## Запуск через Docker

Для запуска необходим Docker Desktop.

1. Создать файл `.env` на основе `.env.example`.
2. Указать в `.env` настройки базы данных и JWT-секрет.
3. Выполнить команду:

```bash
docker compose up -d --build
```

После запуска приложение доступно по адресу:

`http://localhost:8080`

## REST API

Основные эндпоинты:

| Метод | URL | Описание |
|---|---|---|
| POST | `/auth/register` | Регистрация |
| POST | `/auth/login` | Авторизация |
| GET | `/tasks` | Получение списка задач |
| POST | `/tasks` | Создание задачи |
| PUT | `/tasks/{id}` | Редактирование задачи |
| PATCH | `/tasks/{id}/status` | Изменение статуса |
| DELETE | `/tasks/{id}` | Удаление задачи (ADMIN) |

Для доступа к защищённым API-эндпоинтам используется JWT-токен.

## Веб-интерфейс

Страница входа:

`http://localhost:8080/login`

После авторизации доступны просмотр, создание и редактирование задач.

Удаление задач доступно только пользователям с ролью `ADMIN`.

## Тестирование

Запуск тестов:

```bash
mvn clean test
```

В проекте реализовано **17 автоматизированных тестов** с использованием JUnit 5 и Mockito.
